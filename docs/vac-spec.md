# VAC 欄位與決策規格

每個Shot對應一份任務。範本使用JSON（可直接閱讀，也可轉成YAML）；沒有綁定特定平台。

| 欄位 | 定義 |
|---|---|
| schema_version | 任務欄位格式版本，與project版本概念分開 |
| shot_id / goal | 唯一鏡號與可觀察敘事目的 |
| inputs | 參考圖、資產、上一鏡狀態；空陣列表示尚未提供 |
| continuity | 起始與結束狀態、視線及道具位置 |
| image / video | 圖像五要素、動作運鏡情緒、生成及保留時長 |
| audio | 台詞、旁白、是否需要畫面嘴型同步 |
| limits | 最大重試次數（不含首次）、含幣別的成本上限 |
| outputs | 預期檔案角色與命名，不代表檔案已產生 |
| acceptance | 可觀察的通過條件與證據 |
| review | 當前狀態與人工核准；不可預填已通過 |
| provenance | 工具、模型、版本、seed、資產版本與實際費用 |

## 開始執行前

補齊輸入檔案、導演核准的資產、工具設定、重試次數及成本上限。任一必要欄位為null、參考不存在或圖片未核准，狀態保持draft，不可呼叫付費生成。

## 狀態約定

draft → ready → generating → shot_qc → approved_for_edit → final_review → delivered。
失敗進入needs_revision；超過限額進入human_decision；任務中止記為cancelled。

評估者不得只憑檔案存在就核准內容。生成者與評估者可用同一工具，但需保留獨立檢查紀錄；沒有可靠自動檢查時由人檢查。

## 圖文語意校準

1. 「人物不換裝」指避免無故換裝，劇情換裝需在continuity記錄。
2. 「有台詞」不等於必須數位人；畫面需要同步說話時才啟用口型需求。
3. 皇帝拍桌圖是動作示意；實際首幀應呈現拍桌前的手部狀態。
4. 圖片的右側表述可能含視角歧義；本範例明確使用畫面右側。
5. VAD／VAC／Agent三者是分工定義，不代表Repo已內建可執行Agent。
