## 上傳檔案

1. 解壓ZIP，進入同名資料夾。
2. 在自己的GitHub帳號或組織建立Repo，依需求自行選擇可見性。
3. Upload files時上傳資料夾內的內容，讓README.md位於Repo根目錄；不要只上傳ZIP作為原始碼。
4. 提交後檢查README圖片及四頁介紹的連結。
5. 版本來源為`VERSION`（0.1.0）；授權與公開範圍確定後建立`v0.1.0` tag，必要時再建Release。
