# 第 01 頁｜全流程總覽使用介紹

![第1頁](../assets/images/01-overview.png)

這張總覽卡是整套漫劇製作的入口。使用時，先把故事、參考圖片、預定片長與畫面比例準備好，再由導演確認觀眾是誰、這一集要表達什麼，以及哪些情節不能刪除。VAD協助團隊看懂全流程；VAC把每個任務的輸入、執行、輸出與驗收寫清楚；Agent則依規格呼叫工具、整理素材並記錄結果。

接著依序走過八個關卡：理解劇情、拆解腳本、設計分鏡、鎖定資產、生成圖片、生成影片、粗剪精剪與成片驗收。每個關卡都要有可檢查的產物，例如腳本、分鏡表、核准圖片或驗收紀錄，避免只以「看起來不錯」作為交接標準。圖片與影片生成是兩個獨立關卡，圖片先通過構圖、角色與道具檢查，再投入動態製作。

初次練習可選一段三十秒故事，先完成少量鏡頭，檢查人物是否一致、事件是否清楚、前後狀態是否接得起來，再擴大製作。若某個關卡失敗，就回到造成問題的步驟修正，不必整部重做。圖卡中的編號代表製作順序，並不代表每個關卡耗時相同。

這套流程的核心，是先說清楚什麼叫合格，再要求Agent執行。自動化程度取決於工具能力與整合狀況；本Repo提供方法與範本，不會自行生成影片。完成後應同時交付成片、素材索引與版本紀錄，讓團隊能回查、重做及延續下一集。

團隊討論時，可用這張卡逐格指出目前進度、負責角色與尚未取得的核准。每次交接都附上版本和檢查結果，避免新素材覆蓋舊決策。若故事方向改變，先評估哪些鏡頭受影響，再更新相關任務，保持全組使用同一份規格。
