# 教學與練習

適合企業AI講師、內容企劃、剪輯人員及Agent流程設計者。先備能力為閱讀分鏡與基本剪輯；不要求寫程式。

## 建議90分鐘教學安排

| 時段 | 內容 | 產物 |
|---|---|---|
| 0–15分鐘 | 第01頁總覽與故事目標 | 製作簡報 |
| 15–40分鐘 | 第02頁分鏡與資產 | 3–6鏡分鏡及資產表 |
| 40–65分鐘 | 第03頁VAC填寫與模擬生成 | 一份完整VAC |
| 65–85分鐘 | 第04頁驗收與修正演練 | QC紀錄及交付清單 |
| 85–90分鐘 | 展示與回饋 | 導演決策說明 |

90分鐘涵蓋規格演練；影片生成排隊與實際渲染不納入時數保證。

練習：用同一個30秒故事完成分鏡，選一鏡填VAC，再找同學僅憑規格指出可執行與不可執行之處。

評量100分：目標與故事20、資產與連戲25、VAC可執行性25、驗收與修正20、交付追溯10。80分以上且必要輸入／人工核准規則不缺漏為通過。規格演練合格不代表實際影片已驗收。
