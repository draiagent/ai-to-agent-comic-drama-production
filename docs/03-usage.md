# 第 03 頁｜生成 VAC使用介紹

![第3頁](../assets/images/03-generation.png)

第三頁示範如何把單一鏡頭寫成VAC任務卡。以皇帝拍桌為例，先設定鏡號與目的，再提供核准圖片、角色參考及上一鏡狀態。描述必須具體，例如皇帝保持坐姿、右手在桌上、茶杯在右側，讓執行者知道動作從哪裡開始，也能判斷是否偏離原始構圖。

圖片提示詞使用人物、行為、環境、風格與構圖五個要素；影片提示詞則描述主體動作、運鏡、情緒與環境反應。例如拍桌一次、固定中景、表情憤怒、茶杯輕晃。生成前先核對參考圖是否真的有茶杯，沒有就補圖或調整動作，避免要求模型憑空加入不必要的物件。

執行路線依嘴型需求分流。畫面中的人物需要清楚說話時，可先製作配音，再選擇支援口型同步的工具；旁白、反應鏡頭或無對白畫面，則可使用圖生影片搭配後製音訊。有台詞並不等於每一鏡都必須使用數位人，長句也能搭配反應鏡頭安排節奏。

生成時長與最後使用時長要分開記錄，保留可用片段即可，不必硬用完整輸出。每鏡交付影片、音訊與生成設定，包含模型版本、參考資產和提示詞。驗收時檢查動作、臉部、服裝、嘴型及前後連戲。超過預設重試次數或預算，應交由導演決定簡化動作、改鏡或停止，而不是無限制重新生成。

填表後請另一位同事讀一次，確認他能分辨哪些是固定條件、哪些可調整。遇到工具不支援指定秒數或首尾幀時，先回報限制與替代做法，再由導演調整規格。工具輸出只是候選素材，通過驗收後才可交給剪輯使用。
